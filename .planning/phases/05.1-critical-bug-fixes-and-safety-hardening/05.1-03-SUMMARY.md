## Decisions Made
- Used function parameters rather than a struct wrapper for camera_pos/screen_height/fov_y to keep the API simple and consistent with existing run_frame signature style
- Used debug_assert! (not runtime check) for dense_indirect_shadow bounds since the draw_index is always computed internally and OOB indicates a logic bug, not user input error
- SseConfig updated in-place before WorldUpdate stage rather than passing as separate params to avoid further signature churn
