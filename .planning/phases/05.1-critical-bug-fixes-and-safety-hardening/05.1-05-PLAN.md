<objective>
Harden staging ring exhaustion: when a single frame has too many chunk deltas
to fit in the staging ring, process a partial batch and defer the rest to the
next frame instead of failing the entire frame.
</objective>

<context>
@src/renderer/chunk_pool.rs
@src/renderer/staging_ring.rs
@.planning/phases/05.1-critical-bug-fixes-and-safety-hardening/05.1-RESEARCH.md

<locked_decisions>
- D-01: In record_uploads (or wherever staging_ring.allocate is called in a loop), wrap each allocate call in a match. On Err, stop processing and push remaining deltas back.
- D-02: Use a VecDeque or re-insert at position 0 for remaining deltas. Since pending_chunk_deltas is likely a Vec, converting the remainder to push back is acceptable.
- D-03: Log a warning with the count of deferred deltas: `log::warn!("staging ring exhausted: deferred {} chunk deltas to next frame", remaining)`.
</locked_decisions>
</context>
