  <name>Task 1: Implement ChunkJobQueue and spawn_chunk_job</name>
  <files>src/streaming/job_queue.rs, src/streaming/job_runner.rs, src/streaming/mod.rs</files>
  <behavior>
    - PrioritizedTask { key: ChunkKey, lod_level: u8, sse_bits: u32 } where sse_bits = f32::to_bits(sse_value)
    - PrioritizedTask implements Ord by sse_bits so BinaryHeap is a max-heap (highest SSE = highest priority)
    - ChunkJobQueue { inner: Mutex<BinaryHeap<PrioritizedTask>>, capacity: usize }
    - enqueue(task) -> Option<PrioritizedTask>: if len < capacity push and return None; else collect all, sort ascending by sse_bits, remove index 0 (lowest SSE = evicted), push remainder + new task, return evicted
    - drain_up_to(n) -> Vec<PrioritizedTask>: pop up to n from max-heap (highest SSE first)
    - cancel_queued(key: ChunkKey) -> bool: drain all, filter out matching key, re-push remainder, return whether found
    - spawn_chunk_job(pool: &rayon::ThreadPool, task: PrioritizedTask, sender: mpsc::Sender<ChunkJobResult>) -> Arc<AtomicBool>:
        Arc<AtomicBool> cancel_flag = Arc::new(AtomicBool::new(false))
        pool.spawn(move closure): check cancel_flag.load(Ordering::Relaxed); if true send Cancelled result; else send Generated(vec![0u8;8].into_boxed_slice()) result
        return Arc clone of cancel_flag
    - test queue_evicts_lowest_sse: capacity=2, enqueue sse=1.0/2.0/3.0; third enqueue returns evicted task with sse=1.0
    - test queue_drain_highest_first: enqueue sse=1.0/3.0/2.0, drain_up_to(2) returns sse=3.0    - test cancel_queued_removes: enqueue one task, cancel_queued(key) returns true, queue len is 0
    - test spawn_sends_result: spawn_chunk_job with fresh pool, recv() on receiver returns Ok within 2s
    - test spawn_cancelled_result: set cancel flag true before rayon fires; result outcome matches Cancelled
  </behavior>
