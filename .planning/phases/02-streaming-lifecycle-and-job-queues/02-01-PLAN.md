  <behavior>
    - OctreeNode { x: i32, y: i32, z: i32, lod_level: u8 } — derives Debug, Clone, Copy
    - StreamingOctree { nodes: Vec<OctreeNode> }
    - StreamingOctree::build(config: &LodConfig, origin: (i32,i32,i32), radius_chunks: u32) -> StreamingOctree:
        For each lod 0..config.levels, tiles a uniform grid of nodes in [-radius_chunks, +radius_chunks]^3 around origin. At lod=0 step=1; at lod=1 step=8; at lod=2 step=64 (matches the 4m/32m/256m distances). Nodes at coarser LOD only added if outside the finer LOD's radius (no overlap). Simple conservative check: if lod>0 and node falls within radius_chunks/4 of origin skip        it (executor's discretion on exact boundary math).
    - compute_sse(geo_err: f32, screen_h: u32, dist: f32, fov_rad: f32) -> f32:
        formula: (geo_err * screen_h as f32) / (2.0 * dist * (fov_rad / 2.0).tan())
        returns 0.0 if dist <= 0.0 (divide-by-zero guard)
    - diff_active_set(octree: &StreamingOctree, camera_pos: [f32;3], config: &SseConfig, lod_config: &LodConfig, current_active: &std::collections::HashSet<ChunkKey>) -> (Vec<ChunkKey>, Vec<ChunkKey>):
        returns (to_activate, to_deactivate)
        for each node compute dist from camera_pos to node centre, compute_sse using lod_config.lod_geo_errors[node.lod_level as usize]
        node is "wanted" if sse >= config.threshold_px (frustum check is a stub always returning true)
        to_activate = wanted nodes not in current_active
        to_deactivate = current_active keys not in wanted set
    - test sse_known_value: compute_sse(4.0, 1080, 10.0, 1.0472) is within 1.0 of 424.0
    - test sse_zero_dist: compute_sse(4.0, 1080, 0.0, 1.0472) returns 0.0, no panic
    - test diff_activate_all: empty current_active with high threshold-exceeding SSE returns all octree nodes in to_activate
    - test diff_deactivate_none: all nodes in current_active already, same conditions -> to_activate is empty
  </behavior>
