egui-ash backend scope (hand-written — egui-wgpu is the reference):
- Input:  egui::TexturesDelta (font atlas upload on first frame and on change)
         Vec<egui::ClippedPrimitive> (draw calls each frame)
- Output: draw calls recorded into the active command buffer
- Pipeline: graphics pipeline with:
    vertex shader:   vec2 pos + vec2 uv + u32 color (sRGB packed)
    fragment shader: texture(sampler, uv) * color_linear
    push constants:  [f32; 2] screen_size (width, height in points)
    blend:           alpha premultiplied
    topology:        TRIANGLE_LIST
- Font atlas: upload via StagingBuffer -> device-local VkImage
              format: R8G8B8A8_SRGB, layout SHADER_READ_ONLY_OPTIMAL
- Vertex/index buffers: one per frame (or dynamic, executor's discretion)
  MemoryLocation::CpuToGpu so CPU can write each frame

      pub size: vk::DeviceSize,

  impl StagingBuffer {
      pub fn new(r: &mut Renderer, size: vk::DeviceSize) -> anyhow::Result<Self>
        - Create VkBuffer with TRANSFER_SRC usage, EXCLUSIVE sharing
        - Query memory requirements via get_buffer_memory_requirements
        - Allocate via r.allocator.allocate() with MemoryLocation::CpuToGpu, linear=true
        - Bind buffer memory via bind_buffer_memory

      pub fn write(&mut self, data: &[u8])
        - Get mapped ptr from allocation.mapped_ptr() (CpuToGpu is always mapped)
        - ptr::copy_nonoverlapping into the slice

      pub fn copy_to(
          &self, r: &Renderer, dst: vk::Buffer, size: vk::DeviceSize,
      ) -> anyhow::Result<()>
        - Allocate a one-shot command buffer from r.command_pool
        - begin (ONE_TIME_SUBMIT), record copy_buffer, end
        - Submit to r.device_ctx.graphics_queue; wait via queue_wait_idle
        - Free the one-shot command buffer

      pub fn destroy(self, r: &mut Renderer) -> anyhow::Result<()>
        - r.allocator.free(self.allocation)?
        - r.device_ctx.device.destroy_buffer(self.buffer, None)
  }
