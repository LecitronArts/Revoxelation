<locked_decisions>
- D-01: scene_buffer layout (contiguous regions within one SSBO):
  Region 0: GpuChunkInstance[capacity]  — per-slot chunk metadata (48 bytes each)
  Region 1: DrawIndexedIndirectCommand[capacity] — indirect templates (20 bytes each)
  Region 2: u32[capacity] — draw slot mapping (4 bytes each)
  Region 3: DrawIndexedIndirectCommand[capacity] — dense indirect output (20 bytes each)
  All regions 16-byte aligned at region boundaries.
- D-02: GpuChunkInstance struct (48 bytes, #[repr(C)]):
  ```
  aabb_min: [f32; 3],      // 12 bytes
  material_id: u32,        // 4 bytes (replaces slot_id, used in Plan 04 for material lookup)
  aabb_max: [f32; 3],      // 12 bytes
  lod_level: u32,          // 4 bytes
  chunk_origin: [f32; 3],  // 12 bytes
  chunk_scale: f32,        // 4 bytes
  ```
- D-03: Cull shader receives region offsets as additional push constants or calculates them from capacity uniform. Decision: cull shader push constant expanded to include capacity (u32), from which all region offsets are derived in-shader.
- D-04: Vertex shader keeps using `gl_InstanceIndex` (= firstInstance = slot_id) to index GpuChunkInstance array. For instanceCount=1 draws, gl_InstanceIndex == firstInstance, so this is safe. gl_DrawID is NOT needed — firstInstance already carries the slot_id through IndirectCount in Plan 05-05.
- D-05: scene_buffer usage flags: TRANSFER_DST | STORAGE_BUFFER | INDIRECT_BUFFER (for the dense indirect region).
- D-06: ChunkPool::record_upload and record_remove update scene_buffer regions via staging ring, using calculated offsets into the unified buffer.
- D-07: BindlessTable binding 0 now points to scene_buffer (all 4 regions as a single SSBO). Shader uses `capacity` uniform to calculate region offsets in-shader. Bindings 1-3 become free for future use.
  Updated binding layout after merge:
  - binding 0: scene_buffer SSBO (all 4 regions) — COMPUTE | VERTEX
  - binding 1: (available for future use)
  - binding 2: (available for future use)
  - binding 3: (available for future use)
  - binding 4: frustum planes SSBO — COMPUTE
  - binding 5: draw count SSBO — COMPUTE
  - binding 6: Hi-Z config SSBO — COMPUTE
  - binding 7: Hi-Z pyramid sampler — COMPUTE
  - binding 8: material SSBO (Plan 04) — FRAGMENT
  - binding 9: texture array sampler (Plan 04) — FRAGMENT
- D-08: Cull shader push constant expands to: `{ active_draw_count: u32, capacity: u32 }` (8 bytes total).
</locked_decisions>
