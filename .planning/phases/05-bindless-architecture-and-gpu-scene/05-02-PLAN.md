<objective>
Create a unified BindlessTable that owns descriptor set 0 with Vulkan 1.2
UPDATE_AFTER_BIND and PARTIALLY_BOUND flags. Migrate both cull_pipeline and
mesh_pipeline to use this shared set 0, deleting their per-pipeline descriptor
infrastructure. Update all shaders to the new binding layout.
</objective>

<locked_decisions>
- D-01: BindlessTable descriptor set layout (set 0):
  - binding 0: STORAGE_BUFFER (scene/metadata SSBO) — COMPUTE | VERTEX stage
  - binding 1: STORAGE_BUFFER (indirect templates) — COMPUTE stage
  - binding 2: STORAGE_BUFFER (draw slots) — COMPUTE stage
  - binding 3: STORAGE_BUFFER (dense indirect output) — COMPUTE stage
  - binding 4: STORAGE_BUFFER (frustum planes) — COMPUTE stage
  - binding 5: STORAGE_BUFFER (draw count) — COMPUTE stage
  - binding 6: STORAGE_BUFFER (Hi-Z config) — COMPUTE stage
  - binding 7: COMBINED_IMAGE_SAMPLER (Hi-Z pyramid) — COMPUTE stage
  - binding 8: STORAGE_BUFFER (material SSBO, reserved for Plan 04) — FRAGMENT stage
  - binding 9: COMBINED_IMAGE_SAMPLER (texture array, reserved for Plan 04) — FRAGMENT stage
  Bindings 8-9 are created with PARTIALLY_BOUND so they can remain unbound until Plan 04 fills them.
- D-02: All bindings get `PARTIALLY_BOUND | UPDATE_AFTER_BIND` flags. Layout uses `UPDATE_AFTER_BIND_BIT`. Pool uses `UPDATE_AFTER_BIND_BIT`.
- D-03: BindlessTable provides `register_buffer(binding, buffer, range)` and `register_image(binding, view, sampler, layout)` methods that call `vkUpdateDescriptorSets`.
- D-04: BindlessTable is constructed BEFORE cull_pipeline and mesh_pipeline. Both pipelines receive `&bindless.descriptor_set_layout` for their pipeline layout creation.
- D-05: Cull pipeline push constants remain: COMPUTE stage, offset 0, size 4 bytes (active_draw_count).
- D-06: Mesh pipeline push constants remain: VERTEX stage, offset 0, size 80 bytes (CameraUniforms).
- D-07: Both pipelines share the SAME pipeline layout (since they share set 0 and only differ in push constant ranges). OR: each pipeline has its own layout with the shared set_layout + its own push constant range. Decision: each pipeline keeps its own pipeline_layout with the shared set_layout, because push constant ranges differ.
- D-08: submit_frame binds set 0 once for compute, and once for graphics (bind point differs). Or bind once per pipeline bind call. Decision: bind descriptor set at each cmd_bind_pipeline point (compute for cull, graphics for mesh).
- D-09: Delete descriptor_pool, descriptor_set_layout, descriptor_set from ChunkCullPipeline and ChunkMeshPipeline structs. Move the frustum_planes_buffer, draw_count_buffer, hiz_config_buffer ownership to BindlessTable (or keep in cull pipeline but register them with BindlessTable).
  Decision: Keep the auxiliary buffers (frustum planes, draw count, hiz config) in ChunkCullPipeline for locality, but register them with BindlessTable at construction time.
- D-10: Shader changes are binding-compatible (same set 0, same binding indices for cull shader). Mesh vertex shader binding 0 remains metadata SSBO. Fragment shader unchanged for now (texture sampling added in Plan 04).
</locked_decisions>
