<objective>
Create a block material system with per-face texture indices, a 2D texture array
for all block textures, and fragment shader sampling via bindless descriptors.
8 initial block types display distinct textures per face (top/side/bottom).
</objective>

<locked_decisions>
- D-01: BlockMaterial struct (#[repr(C)], 8 bytes):
  ```
  top_texture: u16,     // texture array layer for +Y face
  side_texture: u16,    // texture array layer for ±X/±Z faces
  bottom_texture: u16,  // texture array layer for -Y face
  flags: u16,           // bit flags: 0x01 = emissive, 0x02 = transparent (reserved for future)
  ```
- D-02: MaterialTable: Vec<BlockMaterial> indexed by block_id. Material SSBO uploaded once at startup (small buffer, CpuToGpu or staging copy).
- D-03: 8 initial block types with texture assignments:
  - 0: Air (no rendering)
  - 1: Dirt — all faces: dirt texture
  - 2: Grass — top: grass_top, side: grass_side, bottom: dirt
  - 3: Stone — all faces: stone texture
  - 4: Sand — all faces: sand texture
  - 5: Log — top/bottom: log_end, side: log_bark
  - 6: Planks — all faces: planks texture
  - 7: Leaves — all faces: leaves texture (flags: transparent bit set)
  - 8: Water — all faces: water texture (flags: transparent bit set)
- D-04: Texture array: VkImage with imageType=2D, arrayLayers=256 (max capacity), 16×16 RGBA8.
  Initial layers populated with programmatically generated simple textures (not art-quality):
  - Dirt: brown base with noise
  - Grass top: green with variation
  - Grass side: green top strip + brown bottom
  - Stone: gray with speckle
  - Sand: yellow-tan with fine noise
  - Log bark: dark brown vertical lines
  - Log end: brown rings pattern
  - Planks: tan with horizontal lines
  - Leaves: green with transparency dots
  - Water: blue with wave pattern
  Total: ~10 unique texture layers for 8 block types.
- D-05: Texture generation: pure Rust procedural (no PNG loading for initial textures). Add `image` crate dependency for future PNG loading support, but initial textures are generated in code.
- D-06: Fragment shader changes:
  - Input: `flat uint v_block_id`, `vec3 v_face_normal` (from vertex shader)
  - Uniform: material SSBO (binding 8), texture array sampler (binding 9)
  - Logic: read BlockMaterial from material_ssbo[v_block_id], select texture_index based on face_normal (+Y=top, -Y=bottom, else=side), sample texture array at that layer, output color.
  - GLSL extension: `GL_EXT_nonuniform_qualifier` for nonuniformEXT on texture index.
- D-07: Vertex shader changes:
  - Output `flat uint v_block_id` (from in_packed.y & 0xFFFF, already extracted).
  - Output `vec3 v_face_normal` (derived from face_index: axis + sign).
  - Remove the old hash-based v_color computation.
- D-08: UV coordinates: derived from vertex position within the quad. For 16×16 textures on 1-block-wide faces, UV = fract(world_pos) projected onto the face plane. Vertex shader outputs `vec2 v_uv`.
- D-09: Material SSBO registered at bindless binding 8. Texture array sampler registered at bindless binding 9.
- D-10: The `image` crate is added to Cargo.toml for future PNG loading; initial textures are procedural.
</locked_decisions>
</context>
