## Decisions Made
- MSAA_SAMPLES=TYPE_4 as pub const in swapchain.rs, imported by all pipelines (avoids scattered magic values)
- 4-attachment MSAA render pass with SAMPLE_ZERO depth resolve (universally supported, conservative for Hi-Z)
- MSAA intermediate attachments use TRANSIENT_ATTACHMENT usage flag for potential lazily-allocated memory
- depth_store_op test updated: DONT_CARE is correct for MSAA intermediates (resolved data goes to single-sample targets)
