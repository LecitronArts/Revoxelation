## Accomplishments

- Camera movement uses delta_time for frame-rate independence; configurable move_speed (default 10.0) and mouse_sensitivity (default 0.1)
- GpuChunkInstance expanded to 64 bytes with spawn_time field for chunk activation timing
- Fragment shader computes fade_alpha from (current_time - spawn_time) / 0.5s with Bayer 8x8 dither discard
- current_time passed to GPU via MeshletDrawPushConstants (84->88 bytes)
- Octree parent_of correctly skips out-of-range parent coordinates instead of clamping (MED-12)
- hecs dependency removed from Cargo.toml (REFAC-06)
- ChunkDrawMetadata dead struct deleted from chunk_pool.rs (REFAC-07)
- Skirt emission code removed from greedy.rs (REFAC-07/MSHL-05)

## Decisions Made

- Camera sensitivity is a Camera struct field (not external param) for cleaner API
- GpuChunkInstance padded to 64 bytes (was 48) to maintain Pod/Zeroable and std430 alignment
- Alpha dither (Bayer 8x8 from common.glsl) used for fade-in — no blend state changes needed
- FADE_DURATION = 0.5s hardcoded in vertex shader (fast enough to be pleasant, slow enough to notice)
- Octree skip-link: out-of-range parents get None (no link) — prevents false topology connections
