# Phase 06.1 Plan 04: Shader Parameterization + Shared Includes + SPIR-V Optimization Summary

**Eliminated all shader magic numbers via push constants, created shared common.glsl include system, and enabled SPIR-V performance optimization in build.rs**

## Performance

- **Duration:** 8 min
- **Tasks:** 3
- **Files modified:** 12

## Accomplishments
- Created `shaders/common.glsl` shared include with all common definitions (GpuChunkInstance, GpuMeshlet, face_normal, Bayer dither, LOD transition, CameraUniforms, MIN_LOD_DISTANCE)
- Parameterized all shader magic numbers: `screen_height` and `sse_threshold` flow from Rust push constants through all rendering paths (ComputeIndirectPath, MeshShaderPath, meshlet_cull.comp)
- Enabled SPIR-V OptimizationLevel::Performance and shaderc include callback in build.rs
- Removed duplicated struct definitions from individual shaders (chunk_cull.comp GpuChunkInstance, hardcoded 0.001 constants)

## Task Commits

Each task was committed atomically:

1. **Task 1: Add test stubs for shader parameterization, includes, optimization** - `a676b04` (test)
2. **Task 2: Create common.glsl shared include and wire build.rs include callback** - `c7fa506` (feat)
3. **Task 3: Parameterize shader magic numbers + add #include directives** - `ea7c81e` (feat)

## Files Created/Modified
- `shaders/common.glsl` - Shared shader include (GpuChunkInstance, GpuMeshlet, face_normal, Bayer, LOD transition, CameraUniforms)
- `build.rs` - shaderc include callback + OptimizationLevel::Performance
- `shaders/chunk_cull.comp` - Added #include "common.glsl", removed duplicate GpuChunkInstance struct
- `shaders/meshlet_cull.comp` - Replaced hardcoded 0.001 with MIN_LOD_DISTANCE
- `shaders/meshlet_draw.frag` - Replaced hardcoded 0.001 threshold with MIN_LOD_DISTANCE
- `src/renderer/mesh_pipeline.rs` - New MeshletDrawPushConstants (84B), sse_threshold parameter on trait
- `src/renderer/submit.rs` - Pass renderer.sse_threshold to MeshletPipeline::record_draw
- `tests/phase6_1_polish.rs` - 4 source-grep tests for parameterization, includes, optimization

## Decisions Made
- MeshletDrawPushConstants extends CameraUniforms (80B) with screen_height + sse_threshold = 84 bytes total for the vertex shader in ComputeIndirectPath
- MeshShaderPath already had sse_threshold/screen_height in MeshletCullPushConstants (task shader); now receives sse_threshold from renderer instead of hardcoded 2.0
- MIN_LOD_DISTANCE = 0.001 defined once in common.glsl and used by meshlet_cull.comp, meshlet_draw.frag, and compute_lod_transition
- chunk_cull.comp now includes common.glsl for GpuChunkInstance (previously had its own inline copy)
