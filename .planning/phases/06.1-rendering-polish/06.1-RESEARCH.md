# Phase 06.1: Rendering Polish, Bug Fixes, and Architecture Refactoring — Research

**Researched:** 2026-03-28
**Source:** Deep code review of entire codebase (4 parallel review agents)

## 1. Critical Vulkan Bugs (CRIT-01 ~ CRIT-07)

### CRIT-01: Depth store_op DONT_CARE
**File:** `src/renderer/swapchain.rs:520`
**Root cause:** `vk::AttachmentStoreOp::DONT_CARE` on depth attachment. submit.rs reads depth buffer for Hi-Z pyramid generation after render pass ends.
**Consequence:** GPU may discard depth data — Hi-Z pyramid contains garbage. Works on NVIDIA (driver retains data), fails on AMD/Intel (intermittent geometry flicker/disappear).
**Fix:** Change to `.store_op(vk::AttachmentStoreOp::STORE)`. One-line fix, zero risk.

### CRIT-02: scene_buffer grow flat copy
**File:** `src/renderer/chunk_pool.rs:537-547`
**Root cause:** `grow_capacity()` copies old scene_buffer with single `BufferCopy` at offset 0. But scene_buffer has 4 regions (instances, indirect, draw_slots, dense_indirect) whose offsets depend on capacity. When capacity doubles, all region offsets change.
**Layout:** `scene_buffer_region_offsets(cap)` returns (inst_off=0, indirect_off=cap*48, slot_off=cap*48+cap*20, dense_off=cap*48+cap*20+cap*4, total).
**Fix:** Replace single BufferCopy with 4 separate copies:
```rust
// Region 0 (instances): both start at 0, just copy
let (old_inst, old_ind, old_slot, old_dense, _) = scene_buffer_region_offsets(old_cap);
let (new_inst, new_ind, new_slot, new_dense, _) = scene_buffer_region_offsets(new_cap);
let copies = [
    vk::BufferCopy { src_offset: old_inst, dst_offset: new_inst, size: old_cap * 48 },
    vk::BufferCopy { src_offset: old_ind, dst_offset: new_ind, size: old_cap * 20 },
    vk::BufferCopy { src_offset: old_slot, dst_offset: new_slot, size: old_cap * 4 },
    vk::BufferCopy { src_offset: old_dense, dst_offset: new_dense, size: old_cap * 20 },
];
```
Also re-register all bindless bindings that reference scene_buffer sub-regions (line 574 only re-registers binding 0).

### CRIT-03: Push constants Vulkan spec violation
**File:** `src/renderer/mesh_pipeline.rs:526-532`
**Root cause:** Pipeline layout has two ranges: TASK_EXT [0,40) and MESH_EXT [48,128). Bytes [40,48) are a gap. But code pushes [0,128) with `TASK_EXT | MESH_EXT` in one call. Vulkan requires every pushed byte to be covered by a range for each specified stage.
**Fix:** Split into two `cmd_push_constants` calls:
```rust
device.cmd_push_constants(cmd, layout, TASK_EXT, 0, &bytes[0..40]);
device.cmd_push_constants(cmd, layout, MESH_EXT, 48, &bytes[48..128]);
```

### CRIT-04: MeshletPool counters never decrement
**File:** `src/renderer/chunk_pool.rs:1236-1239`
**Root cause:** `record_remove()` only removes from `chunk_ranges` HashMap. `active_meshlet_count`, `active_vertex_count`, `active_tri_count` never decrease. Cull shader dispatches for deleted meshlets; GPU buffer eventually overflows.
**Fix:** In `record_remove`, look up the range for the key, subtract counts, and implement a free-list or compaction for the GPU buffer regions. Minimum viable: track free ranges, reuse on next upload. Counters must accurately reflect live data.

### CRIT-05: SSE distance uses wrong coordinate space
**File:** `src/runtime/scheduler.rs:191-196`
**Root cause:** `key.x as f32 - camera_pos[0]` mixes chunk-index coordinates with world-space camera position. Chunk (3,0,0) at LOD0 is at world position 12m (3 * 64 * 0.0625), but code uses 3.0.
**Fix:**
```rust
let chunk_world_edge = CHUNK_EDGE as f32 * (1 << key.lod_level) as f32 * BLOCK_SIZE;
let wx = key.x as f32 * chunk_world_edge + chunk_world_edge * 0.5;
let wy = key.y as f32 * chunk_world_edge + chunk_world_edge * 0.5;
let wz = key.z as f32 * chunk_world_edge + chunk_world_edge * 0.5;
let dx = wx - camera_pos[0];
// ...
```
Where `BLOCK_SIZE = 1.0/16.0` and `CHUNK_EDGE = 64`.

### CRIT-06: deactivate_chunk doesn't handle Queued/Loading
**File:** `src/runtime/scheduler.rs:453-474`
**Root cause:** Only handles `Active | Upgrading | Downgrading` states. Queued chunks remain in Queued state after deactivation — can never be re-activated (activation checks `state == Inactive`).
**Fix:** Add state transitions:
- Queued → Inactive (remove from job queue, remove cancel_flag, transition state)
- Loading → set cancel flag + mark as "pending deactivation" so handle_job_result transitions to Inactive instead of Active

### CRIT-07: Hi-Z pass 0 equal src/dst resolution
**File:** `src/renderer/hiz.rs:401-461`, `shaders/hiz_generate.comp`
**Root cause:** hiz_generate.comp does 2×2 max sampling from `(coord*2+0.5)*texel_size`. When pass 0 has src=depth and dst=hiz_mip0 at same resolution, the 2× coordinate multiplier samples outside the valid region for the right/bottom half of the image.
**Fix:** Either:
(a) Make hiz mip 0 half-resolution (standard approach — first mip = half res), OR
(b) Add a special pass 0 path in the shader that does 1:1 copy, OR
(c) Start the generate loop from mip 1, with mip 0 being a direct depth→hiz copy via vkCmdCopyImage.
Option (c) is cleanest — avoids shader branching.

## 2. High-Priority Bugs (HIGH-01 ~ HIGH-07)

### HIGH-01: egui descriptor set shared across frames
**File:** `src/renderer/egui_backend.rs:511-564`
**Root cause:** Single descriptor set without UPDATE_AFTER_BIND. Font texture update destroys old sampler and writes new descriptor while other frame's command buffer may still reference it.
**Fix:** Either add UPDATE_AFTER_BIND to the descriptor pool/set, or create per-frame descriptor sets (2 sets for double-buffered). Per-frame is simpler given the existing scratch buffer per-frame model.

### HIGH-02: Destroy order: free before destroy
**File:** `src/renderer/helpers.rs:63-75, 137-149`
**Root cause:** `allocator.free(allocation)` called before `device.destroy_buffer(buffer)`. Vulkan spec requires destroying the resource (unbinding from memory) before freeing the memory.
**Fix:** Swap the two lines in both `destroy_allocated_buffer` and `destroy_allocated_image`.

### HIGH-03: ChunkStateStore never removes entries
**File:** `src/streaming/state_store.rs`
**Root cause:** No `remove()` method. Chunks that go Inactive remain in the HashMap forever.
**Fix:** Add `pub fn remove(&mut self, key: &ChunkKey)` and call it when transitioning to Inactive in the scheduler (after all cleanup is done).

### HIGH-04: cancel_flags leak
**File:** `src/runtime/scheduler.rs:254, 354, 454`
**Root cause:** Flags created on enqueue but never removed for Queued deactivation (no job result comes back to trigger cleanup).
**Fix:** In `deactivate_chunk`, for Queued state: `cancel_flags.remove(&key)`. For Loading state: flag is consumed by `handle_job_result` — but add explicit cleanup there too.

### HIGH-05: Dirty mesh records leak
**File:** `src/meshing/invalidation.rs:69-83`
**Root cause:** `mark_dirty` creates records for neighbors without payloads. `run_mesh_sync` skips them (no payload) but doesn't remove them from the dirty HashMap.
**Fix:** When payload is None in `run_mesh_sync`, remove the key from the dirty map.

### HIGH-06: Job queue eviction doesn't compare SSE
**File:** `src/streaming/job_queue.rs:74-91`
**Root cause:** New task always replaces lowest-SSE evicted task, even if new task has lower SSE.
**Fix:** After identifying the lowest-SSE task, compare with new task. If new task SSE ≤ evicted SSE, reject the new task instead.

### HIGH-07: Bindless stageFlags missing TASK/MESH
**File:** `src/renderer/bindless.rs`
**Root cause:** Descriptor bindings only specify `VERTEX | FRAGMENT | COMPUTE` stage flags. Mesh shader path needs `TASK_SHADER_BIT_EXT | MESH_SHADER_BIT_EXT`.
**Fix:** Add these flags to all relevant bindings in the descriptor set layout. Should be conditional on `mesh_shader_supported` to avoid requiring the extension when not used.

## 4. Rendering Polish (POLISH-01 ~ POLISH-09)

### POLISH-01: Shader parameterization
**Files:** meshlet_draw.vert:133-135, meshlet.mesh:190-192, meshlet_cull.comp:186-191
**Hardcoded values:** `screen_h=1080.0`, `threshold=2.0`, `dist<0.001`
**Fix:** Add `screen_height` and `sse_threshold` to the push constants in meshlet_draw.vert and meshlet.mesh (currently only in meshlet_cull.comp). Expand CameraUniforms push constant struct or add a separate UBO.

### POLISH-02: Texture mipmaps + anisotropic filtering
**Files:** src/renderer/texture_array.rs, src/renderer/mod.rs
**Fix:** Generate mipmap chain for texture array (vkCmdBlitImage per mip level), create sampler with `maxAnisotropy=16.0` and `anisotropyEnable=true`.

### POLISH-03: Anti-aliasing
**Files:** src/renderer/swapchain.rs, src/renderer/mesh_pipeline.rs
**Fix:** Add MSAA 4× — create multisample color/depth images, resolve to swapchain image. Requires modifying render pass (add resolve attachment), pipeline (multisample state), and framebuffer creation.

### POLISH-04: Shared shader includes

**Fix:** Use shaderc `set_include_callback` to support `#include "common.glsl"`. Extract: face_normal_from_index, GpuChunkInstance struct, Bayer matrix, LOD transition logic, CameraUniforms.

### POLISH-05: unwrap/panic removal (overlaps MED-10,11)

### POLISH-06: GPU readback counters
**Files:** submit.rs, app.rs:349-359, perf_counters.rs
**Fix:** Create readback buffer, copy meshlet_count_buffer to readback after dispatch, read previous frame's value. Show actual culled count in HUD.

### POLISH-07: Shader compilation optimization
**File:** build.rs
**Fix:** Add `options.set_optimization_level(shaderc::OptimizationLevel::Performance)`.

### POLISH-08: Chunk fade-in
**Files:** shaders/meshlet_draw.frag, shaders/chunk_mesh.frag, chunk_pool.rs
**Fix:** Add per-chunk `spawn_time` or `fade_alpha` to GpuChunkInstance. Fragment shader fades alpha from 0→1 over ~0.5s based on frame time - spawn_time.

### POLISH-09: Camera smoothing

**Fix:** Use `delta_time` for movement speed, add configurable `mouse_sensitivity` and `move_speed` to RuntimeConfig. Ensure frame-rate-independent movement.

## 5. Architecture Refactoring (REFAC-01 ~ REFAC-08)

### REFAC-01: Split Renderer struct
**Current:** 38 fields in `Renderer` (renderer/mod.rs:63-103), 12 are `Option<T>`.
**Target structure:**
```rust
pub struct VulkanCore { instance, device_ctx, surface, swapchain_ctx, ... }
pub struct PipelineSet { mesh_pipeline, cull_pipeline, meshlet_cull_pipeline, meshlet_pipeline, ... }
pub struct PoolManager { chunk_pool, meshlet_pool, bindless, staging_ring, ... }
pub struct Renderer { core: VulkanCore, pipelines: PipelineSet, pools: PoolManager, egui: EguiBackend, ... }
```
**Risk:** HIGH — touches every file in renderer/. Must be done LAST after all bug fixes.

### REFAC-02: Decompose submit_frame
**Current:** 484 lines in `submit.rs:35-519`.
**Target:** Split into named functions matching the 12-step frame sequence:
1. `acquire_image()` 2. `begin_command_buffer()` 3. `dispatch_chunk_cull()` 4. `dispatch_meshlet_cull()` 5. `generate_hiz()` 6. `begin_render_pass()` 7. `draw_chunks()` 8. `draw_meshlets()` 9. `draw_egui()` 10. `end_render_pass()` 11. `submit_queue()` 12. `present()`

### REFAC-03: Merge create/recreate swapchain
**Files:** swapchain.rs — create_swapchain_context (26-174) and recreate_swapchain_context (183-435) share ~60% code.
**Fix:** Extract shared logic into helper functions, have create and recreate both call them.

### REFAC-04: Extract staging copy helper
**File:** chunk_pool.rs — staging copy pattern repeated 10+ times.
**Fix:** Create `fn stage_and_copy(ring, device, cmd, data, dst_buffer, dst_offset) -> Result<()>`.

### REFAC-05: Binding ID constants
**Files:** app.rs, bindless.rs, chunk_pool.rs, cull_pipeline.rs
**Fix:** Define constants: `BINDING_SCENE=0, BINDING_VERTEX=1, BINDING_INDEX=2, BINDING_COUNT=3, BINDING_FRUSTUM=4, BINDING_DRAW_COUNT=5, BINDING_HIZ_CONFIG=6, BINDING_HIZ_PYRAMID=7, BINDING_MATERIAL=8, BINDING_TEXTURE=9, BINDING_MESHLET_META=10, ...`

### REFAC-06: Remove hecs
**File:** Cargo.toml
**Fix:** Remove `hecs = "0.10"` from dependencies. Grep to confirm zero usage.

### REFAC-07: Dead code cleanup
**Files:** chunk_pool.rs:48-61 (ChunkDrawMetadata), greedy.rs:28-41 (skirt code), app.rs:45-46 (window_extent writes)
**Fix:** Delete dead code, remove #[allow(dead_code)] annotations.

### REFAC-08: Extract App::tick()
**File:** app.rs:157-381
**Fix:** Extract the RedrawRequested body into `App::tick(&mut self) -> Result<FrameOutcome>`. Event loop body becomes ~20 lines.
