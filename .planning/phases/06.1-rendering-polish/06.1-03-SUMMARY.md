# Phase 06.1 Plan 03: Vulkan Resource Safety and Correctness Fixes Summary

**Per-frame egui descriptors, correct destroy order, mesh shader stage flags, Vulkan near-plane formula, fail-safe staging writes, and correct atomic ordering**

## Accomplishments
- Eliminated use-after-free risk on egui font texture updates via per-frame descriptor sets
- Fixed Vulkan destroy-before-free ordering in both buffer and image helpers
- Added TASK_EXT|MESH_EXT stage flags to bindless descriptors and pipeline barriers for mesh shader support
- Corrected frustum near-plane extraction from OpenGL (row3+row2) to Vulkan (row2 only)
- Hardened staging writes with Result return type and unmapped memory checks
- Made max_draw_count dynamic via meshlet_capacity() accessor
- Fixed atomic ordering from Relaxed to Acquire/Release for correct cross-thread cancel flag visibility
