<locked_decisions>
- D-01: Frustum planes are passed via a small SSBO (not push constants) — 6 * vec4 = 96 bytes exceeds what can be combined with camera push constants in the 128B minimum.
- D-02: `FrustumPlanes` struct: 6 `[f32; 4]` values (24 floats, 96 bytes). Extracted from view_proj using Gribb-Hartmann method.
- D-03: Cull shader workgroup: `local_size_x = 64, local_size_y = 1, local_size_z = 1`. Dispatch: `ceil(active_draw_count / 64)` groups.
- D-04: AABB vs frustum test: for each plane, compute the AABB point most in the direction of the plane normal (P-vertex). If dot(plane.xyz, p_vertex) + plane.w < 0, the chunk is outside.
- D-05: Draw count buffer: `vkBuffer` with a single `uint32`. Cull shader resets it to 0 at dispatch start (thread 0), then `atomicAdd` for each visible chunk. Used with `vkCmdDrawIndexedIndirectCount`.
- D-06: The cull shader now writes visible chunks into a compacted output indirect buffer using atomicAdd as the write index. This produces a dense command list for IndirectCount.
- D-07: Require the `khr::draw_indirect_count::Device` extension loader for `vkCmdDrawIndexedIndirectCount`. This is core in Vulkan 1.2 but we're on 1.0 device — check for `VK_KHR_draw_indirect_count` extension.
- D-08: Fallback: if `VK_KHR_draw_indirect_count` is unavailable, keep the existing `cmd_draw_indexed_indirect` path with the full draw count. Culled chunks have instanceCount=0 so they produce no fragments.
- D-09: Cull shader binding layout: binding 0 = metadata SSBO (read), binding 1 = indirect templates (read), binding 2 = draw slots (read), binding 3 = output dense indirect (write), binding 4 = frustum planes (read), binding 5 = draw count (read+write).
</locked_decisions>
</context>
