<locked_decisions>
- D-01: Pipeline cache file: `cache/pipeline.bin`. On startup, load if exists; on shutdown (Renderer::drop), save. Use `vkGetPipelineCacheData` / `vkCreatePipelineCache` with initial data.
- D-02: Cache directory created automatically if it doesn't exist.
- D-03: All `create_graphics_pipelines` and `create_compute_pipelines` calls pass the shared pipeline cache handle.
- D-04: Performance counters: read back the draw count buffer value each frame (small readback, doesn't stall if done properly — copy to a CPU-readable buffer per frame, read the previous frame's value).
- D-05: Counter struct: `GpuPerfCounters { visible_chunks: u32, total_chunks: u32, frame_time_ms: f32, gpu_time_ms: f32 }`.
- D-06: egui HUD: show as a small always-visible overlay panel: "Chunks: {visible}/{total} | Frame: {ms}ms | GPU: {ms}ms".
- D-07: GPU timestamp queries for frame timing (vkCmdWriteTimestamp at start and end of frame command buffer). Requires timestamp support (almost universal).
- D-08: Shader hot-reload (debug only): watch shader source files. On change, recompile with shaderc (already in build deps), recreate pipelines. Feature-gated behind `#[cfg(debug_assertions)]`.
- D-09: Runtime config: simple key-value store (HashMap<String, String>) loaded from an optional `config.toml`. For now just: `hiz_enabled: bool`, `show_hud: bool`, `camera_speed: f32`.
</locked_decisions>
</context>
