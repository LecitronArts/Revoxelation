<objective>
Eliminate all OnceLock<Mutex<>> global singletons (Renderer, StreamingState, MeshingState)
and replace them with an App struct that owns all subsystems via direct fields. Add
env_logger for visible log output and ensure submit_frame errors propagate properly.

This is the foundation plan that all other Phase 4 plans depend on -- clean ownership
enables safe swapchain recreation, camera state management, and staging pipeline control.
</objective>

<locked_decisions>
- D-01: Create an `App` struct in `src/app.rs` that owns `Renderer`, `StreamingState`, `MeshingState`, and `egui::Context` as direct fields. No trait objects or Arc.
- D-02: Convert `run_frame(frame_index: u64)` to accept `&mut StreamingState`, `&mut MeshingState`, `&mut Renderer` as parameters. The scheduler module becomes pure logic with no global state access.
- D-03: Delete `src/renderer/globals.rs` entirely. Remove the `pub mod globals` declaration and all `install_renderer`/`renderer_state` re-exports from `src/renderer/mod.rs`.
- D-04: Move `StreamingState::new()` from `scheduler.rs` into a public constructor. Remove the `static STREAMING` and `static MESHING` OnceLocks.
- D-05: Add `env_logger = "0.11"` to Cargo.toml. Initialize it in `main()` before `app::run()`.
- D-06: The `drain_pending_render_deltas_into_renderer` function becomes a method or receives `&mut` refs directly -- no more double-locking through globals.
- D-07: `submit_frame` error results must be logged with `log::error!` in the event loop. Non-fatal errors (e.g., suboptimal present) should not crash the app.
- D-08: Existing tests that use `run_frame` must be updated to construct local state instead of relying on OnceLock lazy init. If a test currently calls global `run_frame(N)`, it must either construct App-local state or use a test helper.
</locked_decisions>
</context>
