<objective>
Implement classic 4-corner voxel ambient occlusion computed during greedy meshing. Each quad vertex gets an AO value (0-3) based on neighboring block occlusion. AO values are packed into 8 free bits of PackedVertex word0 and interpolated in the fragment shader to produce smooth darkening at block junctions.

Purpose: Voxel AO is the cheapest and most impactful ambient occlusion technique for block worlds. It runs at zero GPU cost (computed during meshing on CPU) and provides per-vertex contact shadows that perfectly match the voxel geometry.
Output: Per-vertex AO values in packed vertex data, smooth AO gradient in fragment shaders, AO integrated with PBR ambient term.
</objective>

  ```rust
  /// Compute voxel AO for a vertex corner on a face.
  /// Checks 3 neighbors: side1, side2, and corner (diagonal).
  /// Returns AO level: 0 (fully occluded/dark) to 3 (fully open/bright).
  ///
  /// For a face on axis `a` at position (x,y,z), the two tangent axes are u,v.
  /// For a corner at (du, dv) where du/dv are -1 or +1 offsets along u,v:
  ///   side1 = block at (x + du*u_axis)
  ///   side2 = block at (x + dv*v_axis)
  ///   corner = block at (x + du*u_axis + dv*v_axis)
  fn compute_corner_ao(
      chunk: &ChunkVoxels,
      neighbors: &ChunkNeighborSet<'_>,
      face_pos: [i32; 3],      // world position of the face
      axis: u8,                 // face normal axis (0=X, 1=Y, 2=Z)
      positive: bool,           // positive or negative face
      du: i32,                  // -1 or +1 along u-tangent
      dv: i32,                  // -1 or +1 along v-tangent
  ) -> u8 {
      let (u_axis, v_axis) = plane_axes_usize(axis);
      let mut s1_pos = face_pos;
      s1_pos[u_axis] += du;
      let mut s2_pos = face_pos;
      s2_pos[v_axis] += dv;
      let mut c_pos = face_pos;
      c_pos[u_axis] += du;
      c_pos[v_axis] += dv;

      let side1 = is_opaque(chunk, neighbors, s1_pos);
      let side2 = is_opaque(chunk, neighbors, s2_pos);
      let corner = is_opaque(chunk, neighbors, c_pos);

      if side1 && side2 {
          0 // fully occluded
      } else {
          3 - (side1 as u8 + side2 as u8 + corner as u8)
      }
  }
  ```

  ```glsl
  // -----------------------------------------------------------------------
  // Voxel AO decoding (LGHT-04)
  // -----------------------------------------------------------------------
  // Bits 24-25 of word0 encode per-vertex AO (0=dark, 3=bright).
  // Convert to float: 0→0.2, 1→0.5, 2→0.75, 3→1.0
  float decode_vertex_ao(uint word0) {
      uint ao_bits = (word0 >> 24) & 0x3u;
      // AO curve: slightly non-linear for better visual contrast
      const float ao_values[4] = float[4](0.2, 0.5, 0.75, 1.0);
      return ao_values[ao_bits];
  }
  ```
