<objective>
Implement screen-space ambient occlusion (SSAO) with multiple algorithm options (GTAO default, HBAO+, classic SSAO). Includes compute shader for AO calculation, bilateral blur for noise reduction, and compositing into the PBR lighting pipeline. Configurable via egui.

Purpose: SSAO adds subtle contact darkening at block edges and corners, providing visual depth and realism to the voxel world. Block junctions and concave areas appear naturally darker.
Output: SSAO compute pipeline, bilateral blur, R8 AO result texture at binding 17, blur intermediate at binding 24, AO composited into fragment lighting (combined with voxel AO), egui algorithm selection and parameter controls.
</objective>

Pipeline layout uses set 0 (bindless) + push constants for SSAO params (algorithm, radius, intensity, sample_count, screen_dims, near, far = 32 bytes).

Then bilateral blur horizontal pass: read binding 17 → write binding 24 (blur intermediate). Then barrier. Then bilateral blur vertical pass: read binding 24 → write binding 17. Then barrier. Transition AO result (binding 17) to SHADER_READ_ONLY for fragment shader consumption.
  - `recreate(renderer, new_width, new_height)`: Destroy and recreate AO images on swapchain resize.
  - `destroy(renderer)`: Clean up all GPU resources.

  **ssao_blur.comp** — Bilateral blur with SEPARATE input/output bindings to comply with Vulkan spec:
  ```glsl
  #version 450
  layout(local_size_x = 8, local_size_y = 8) in;
  layout(push_constant) uniform BlurParams {
      vec2 direction;  // (1,0) for horizontal, (0,1) for vertical
      vec2 texel_size;
  } params;

  // Pass 1 (horizontal): read from binding 17 (AO result), write to binding 24 (blur intermediate)
  // Pass 2 (vertical):   read from binding 24 (blur intermediate), write to binding 17 (AO result)
  //
  // The correct binding pair is selected by dispatching the blur pipeline twice
  // with appropriate image barriers between passes.
  layout(set = 0, binding = 17) uniform sampler2D ao_input_17;
  layout(r8, set = 0, binding = 24) uniform writeonly image2D ao_output_24;
  // For the reverse pass, we need a second variant or use specialization constants.
  // Preferred approach: use push constant uint `pass_index` (0 = horiz, 1 = vert).
  // Pass 0: sample ao_input_17, write ao_output_24
  // Pass 1: sample ao_input_24 (as sampler2D), write ao_output_17 (as writeonly image2D)
  //
  // Since both bindings need to be accessible as both sampler2D and writeonly image2D
  // depending on the pass, declare all 4 and branch on pass_index:
  layout(set = 0, binding = 24) uniform sampler2D ao_input_24;   // for vertical pass read
  layout(r8, set = 0, binding = 17) uniform writeonly image2D ao_output_17; // for vertical pass write

  // Bilateral blur: 7-tap Gaussian weighted by depth similarity
  void main() {
      // Use push constant pass_index to select correct input/output pair
      // Pass 0 (horizontal): read ao_input_17, write ao_output_24
      // Pass 1 (vertical): read ao_input_24, write ao_output_17
  }
  ```

  **IMPORTANT**: Between the two blur passes, insert proper image memory barriers:
  - After horizontal pass: binding 24 transitions from GENERAL (write) → SHADER_READ_ONLY (read), binding 17 transitions from SHADER_READ_ONLY → GENERAL (write)
  - After vertical pass: binding 17 transitions from GENERAL → SHADER_READ_ONLY (for fragment shader sampling)
