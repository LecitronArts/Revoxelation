Current pipeline: build_greedy_mesh() -> PackedMesh -> RenderDelta::Upsert -> ChunkPool (3 buffers: vertex, index, scene).
Phase 6 pipeline: build_greedy_mesh() -> PackedMesh -> build_meshlets_from_packed() -> MeshletMesh -> RenderDelta::Upsert -> MeshletPool (4 SSBOs: meshlet_meta, meshlet_vertex, meshlet_tri, scene_buffer).

PackedVertex is 8 bytes ([u32; 2]). meshoptimizer needs float positions for spatial clustering.
Approach: unpack 7-bit x/y/z from PackedVertex word0 to temporary f32 positions for meshopt::build_meshlets, keep PackedVertex data in final MeshletMesh.

<locked_decisions>
- D-01: meshopt crate version: latest stable (0.2+). Add `meshopt = "0.2"` to [dependencies].
- D-02: MeshletMesh struct contains:
  - meshlets: Vec<MeshletDescriptor> — per-meshlet metadata (offsets, counts, bounds)
  - vertices: Vec<PackedVertex> — re-indexed vertex data (meshlet-local order)
  - triangles: Vec<u8> — local triangle indices (3 bytes per triangle)
  - aabb_min/aabb_max: [f32; 3] — chunk-level AABB (retained from PackedMesh)
- D-03: MeshletDescriptor struct:
  - vertex_offset: u32, triangle_offset: u32, vertex_count: u32, triangle_count: u32
  - center: [f32; 3], radius: f32 — bounding sphere
  - cone_axis: [f32; 3], cone_cutoff: f32 — orientation cone
- D-04: GpuMeshlet (64 bytes, #[repr(C)], bytemuck Pod+Zeroable):
  - center: [f32; 3], radius: f32 (16 bytes)
  - cone_axis: [f32; 3], cone_cutoff: f32 (16 bytes)
  - vertex_offset: u32, triangle_offset: u32, vertex_count: u32, triangle_count: u32 (16 bytes)
  - chunk_slot: u32, lod_level: u32, pad0: u32, pad1: u32 (16 bytes)
- D-05: MeshletPool manages:
  - meshlet_meta_buffer: GpuMeshlet[] SSBO (binding 10)
  - meshlet_vertex_buffer: PackedVertex[] SSBO (binding 11)
  - meshlet_tri_buffer: u32[] SSBO (binding 12) — u8 local indices from meshoptimizer are widened to u32 during MeshletPool::record_upload for INDEX_TYPE_UINT32 IB binding compatibility (see Plan 03 D-08)
  - visible_meshlet_buffer: u32[] SSBO (binding 13) — output of cull, filled in Plan 02
  - meshlet_indirect_buffer: indirect commands SSBO (binding 14) — filled in Plan 03
  - meshlet_count_buffer: u32 SSBO (binding 15) — visible meshlet count, filled in Plan 02
  - scene_buffer: retained from ChunkPool (GpuChunkInstance[], still needed for chunk-level data)
- D-06: Initial meshlet capacity: 65536 meshlets (doubling at 90% fill).
- D-07: Initial vertex capacity: 65536 * 64 = 4M vertices; initial triangle capacity: 65536 * 124 * 3 = ~24M u32 indices (widened from u8; ~96 MB at 4 bytes per index).
- D-08: BindlessTable BINDING_COUNT increases from 10 to 16. New bindings all use STORAGE_BUFFER with COMPUTE stage flags (+ VERTEX for binding 11 in compute path).
- D-09: Per-chunk meshlet range tracked in MeshletPool: HashMap<ChunkKey, (meshlet_start, meshlet_count)> for remove/update operations.
- D-10: cone_weight parameter for meshopt::build_meshlets: 0.5 (balanced spatial vs orientation clustering).
- D-11: PackedMesh is retained as intermediate type. build_greedy_mesh still produces PackedMesh. A new function build_meshlets_from_packed(packed: &PackedMesh) -> MeshletMesh converts it.
</locked_decisions>
