@.planning/phases/06-meshlet-pipeline/06-RESEARCH.md

Nanite-style DAG: groups of ~4 adjacent LOD0 meshlets are merged, simplified via
meshopt::simplify with locked boundary vertices, then re-split via build_meshlets
into LOD1 meshlets. Both LOD0 and LOD1 meshlets coexist in the same MeshletMesh.

SSE-based selection: each meshlet group has a parent_error metric (simplification
error from LOD0->LOD1). At runtime, project error to screen pixels. If below
threshold -> use LOD1 (parent); otherwise -> use LOD0 (children).

Alpha dither: in fragment shader, compute LOD transition factor based on how close
the SSE is to the threshold. Use Bayer 8x8 dithering to smoothly transition over
1-2 frames. Fragments below the dither threshold are discarded.

<locked_decisions>
- D-01: LOD group size: 4 adjacent LOD0 meshlets grouped by spatial proximity (using meshlet bounding sphere centers).
- D-02: Simplification target: reduce triangle count by ~4x per group (target_count = group_total_tris / 4).
- D-03: Boundary vertex detection: vertices shared between meshlets in different groups are marked as locked. Use meshopt::simplify with SimplifyOptions::LockBorder or custom locked vertex list.
- D-04: MeshletDescriptor extended with:
  - lod_level: u8 (0 = original, 1 = simplified)
  - group_id: u32 (which LOD group this meshlet belongs to)
  - parent_error: f32 (simplification error metric, only meaningful for LOD0 meshlets)
- D-05: GpuMeshlet lod_level field (already in D-04 of Plan 01) is populated correctly: 0 for LOD0, 1 for LOD1.
- D-06: LOD selection in meshlet_cull.comp (or meshlet.task):
  ```glsl
  float projected_error = parent_error * screen_height / (2.0 * distance * tan(fov/2));
  bool use_parent = projected_error < sse_threshold; // 2.0 pixels default
  // If LOD0 meshlet and use_parent -> cull (parent LOD1 will render instead)
  // If LOD1 meshlet and !use_parent -> cull (children LOD0 will render instead)
  ```
- D-07: Alpha dither in fragment shader:
  ```glsl
  // Bayer 8x8 dithering matrix
  float bayer8x8(ivec2 p) { /* standard Bayer matrix lookup */ }
  float transition = smoothstep(sse_threshold - 0.5, sse_threshold + 0.5, projected_error);
  // LOD0: fade in as error grows (transition -> 1.0)
  // LOD1: fade out as error grows (1.0 - transition)
  float alpha = (lod_level == 0) ? transition : (1.0 - transition);
  if (alpha < bayer8x8(ivec2(gl_FragCoord.xy) % 8)) discard;
  ```
- D-08: Remove or disable border skirt emission in greedy.rs (the is_skirt path in emit_quads_for_axis). DAG shared vertices replace the skirt approach for seamless LOD transitions.
- D-09: GpuPerfCounters extended with:
  - lod0_meshlets: u32 (visible LOD0 meshlets this frame)
  - lod1_meshlets: u32 (visible LOD1 meshlets this frame)
  - backface_culled: u32, frustum_culled: u32, hiz_culled: u32 (per-mode cull counts)
  - meshlet_ssbo_bytes: u64 (total GPU memory for meshlet SSBOs)
- D-10: egui HUD meshlet panel shows: total meshlets, visible (LOD0/LOD1 breakdown), cull rates, SSBO memory.
- D-11: SSE threshold (default 2.0 pixels) configurable via egui slider.
</locked_decisions>
