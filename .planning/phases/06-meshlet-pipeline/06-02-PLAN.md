Existing chunk_cull.comp uses local_size_x = 64, frustum + Hi-Z culling on chunk AABBs. It writes dense_indirect commands. Phase 6 adds a second level that culls individual meshlets within visible chunks.

NOTE on two-level cascade: The cascade is implicit. meshlet_cull.comp dispatches
over ALL meshlets (total_meshlet_count). Meshlets belonging to chunks that failed
chunk_cull frustum test are naturally culled by the per-meshlet frustum test (their
bounding spheres are outside the frustum). No explicit chunk_visibility_mask SSBO
is needed — the per-meshlet frustum test is sufficient and avoids additional SSBO
binding complexity. chunk_cull still provides value by doing cheap coarse-grained
rejection of entire chunks before the more expensive per-meshlet tests.

<locked_decisions>
- D-01: meshlet_cull.comp layout(local_size_x = 64). One thread per meshlet. Dispatch ceil(total_meshlet_count / 64) workgroups. NOTE: dispatches over all meshlets; the two-level cascade is implicit — meshlets in invisible chunks are naturally eliminated by per-meshlet frustum testing.
- D-02: Push constant struct MeshletCullConfig:
  ```
  uint total_meshlet_count;
  uint enable_backface;    // 0 or 1
  uint enable_frustum;     // 0 or 1
  uint enable_hiz;         // 0 or 1
  ```
  16 bytes total (4 x u32). NOTE: extended to 32 bytes in Task 3 with camera_pos + pad.
- D-03: Backface test: `dot(cone_axis, normalize(camera_pos - center)) < cone_cutoff -> cull`. If cone_cutoff < -1.0, skip test (degenerate cone, never cull).
- D-04: Frustum test: bounding sphere (center, radius) tested against 6 frustum planes. Sphere outside any plane -> cull.
- D-05: Hi-Z test: project bounding sphere to screen-space rect. Sample Hi-Z pyramid max depth at appropriate mip. Sphere depth > max depth -> cull (behind occluders).
- D-06: Compaction: subgroup ballot -> subgroupBallotBitCount for local count -> subgroupElect for single atomicAdd per subgroup -> subgroupBroadcastFirst for global_offset -> write visible_meshlets[global_offset + local_offset] = meshlet_id.
- D-07: Frustum planes are read from binding 4 (already populated by chunk_cull stage). Camera position available via push constants (CameraUniforms) or separate uniform.
- D-08: meshlet_count_buffer (binding 15) is reset to 0 via vkCmdFillBuffer before meshlet cull dispatch.
- D-09: Barrier between chunk_cull and meshlet_cull: COMPUTE_SHADER_WRITE -> COMPUTE_SHADER_READ on visible chunk data; also barrier on meshlet_count_buffer.
- D-10: MeshletCullPipeline is a separate struct from ChunkCullPipeline. Both share the bindless descriptor set.
- D-11: Subgroup feature check: device.rs must validate VK_SUBGROUP_FEATURE_BALLOT_BIT and VK_SUBGROUP_FEATURE_BASIC_BIT via VkPhysicalDeviceSubgroupProperties. Warn if absent, but don't fail (compute path fallback without subgroup optimization is possible later).
- D-12: Camera position for backface test: add camera_pos [f32; 3] to the meshlet cull push constants or pass via the existing frustum planes SSBO (extend it with camera position).
</locked_decisions>
</context>
