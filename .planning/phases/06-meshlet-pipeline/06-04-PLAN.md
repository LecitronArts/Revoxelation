<objective>
Detect VK_EXT_mesh_shader at startup, create task+mesh shaders, implement
MeshShaderPath as a second MeshletPipeline implementation, with automatic
fallback to ComputeIndirectPath when mesh shaders are unsupported.
</objective>

ash 0.38 has ash::ext::mesh_shader::Device extension loader with
cmd_draw_mesh_tasks_ext and cmd_draw_mesh_tasks_indirect_count_ext.

shaderc supports GL_EXT_mesh_shader via ShaderKind::Task and ShaderKind::Mesh
(or TaskNV/MeshNV — need to verify correct kind for EXT variant). May need
compile options with target_env vulkan1_2+.

Plan 04 executes after Plan 03 (wave 4, depends_on: 06-03) because both modify
shared files (src/renderer/mesh_pipeline.rs, src/renderer/mod.rs, build.rs,
tests/phase6_meshlet.rs). Plan 04 extends the MeshletPipeline trait and
mesh_pipeline.rs established by Plan 03 with the MeshShaderPath implementation.

<locked_decisions>
- D-01: Extension detection at device creation in device.rs. Check for "VK_EXT_mesh_shader" in supported device extensions.
- D-02: If detected, enable via VkPhysicalDeviceMeshShaderFeaturesEXT in pNext chain:
  - taskShader = VK_TRUE
  - meshShader = VK_TRUE
  - (multiviewMeshShader and primitiveFragmentShadingRateMeshShader are NOT required)
- D-03: Store mesh_shader_supported: bool in DeviceContext for pipeline selection.
- D-04: Task shader (meshlet.task):
  - local_size_x = 32 (1 thread per meshlet in a workgroup)
  - Same culling logic as meshlet_cull.comp (backface+frustum+Hi-Z)
  - Visible meshlets emit via taskPayloadSharedEXT + EmitMeshTasksEXT
  - Payload: array of visible meshlet IDs (up to 32)
- D-05: Mesh shader (meshlet.mesh):
  - local_size_x = 64 (1 thread per max vertex)
  - layout(triangles, max_vertices = 64, max_primitives = 124) out
  - Reads meshlet ID from task payload
  - Reads GpuMeshlet from binding 10 -> gets vertex_offset, triangle_offset, counts
  - Reads PackedVertex from binding 11 at vertex_offset + gl_LocalInvocationIndex
  - Decodes packed vertex (same logic as meshlet_draw.vert)
  - Sets gl_MeshVerticesEXT[].gl_Position and per-vertex outputs
  - Sets gl_PrimitiveTriangleIndicesEXT[] from triangle data
  - Calls SetMeshOutputsEXT(vertex_count, triangle_count)
- D-06: MeshShaderPath::record_draw uses ash::ext::mesh_shader::Device::cmd_draw_mesh_tasks_indirect_count_ext. Indirect buffer format: VkDrawMeshTasksIndirectCommandEXT { groupCountX, groupCountY, groupCountZ }.
- D-07: For mesh shader path, meshlet_cull.comp is NOT dispatched (task shader does the culling). The chunk-level cull (chunk_cull.comp) still runs. Task shader is dispatched with one workgroup per 32 meshlets in visible chunks.
- D-08: build.rs must handle .task and .mesh extensions. Use shaderc::ShaderKind::Task and shaderc::ShaderKind::Mesh (if available in shaderc 0.10). Compile with target profile vulkan1_2.
- D-09: If shaderc doesn't support .task/.mesh kinds natively, use InferFromSource with appropriate #extension declarations, or map to correct shader kind manually.
</locked_decisions>
</context>
