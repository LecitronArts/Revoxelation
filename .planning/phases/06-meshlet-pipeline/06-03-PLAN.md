Currently chunk_mesh.vert reads PackedVertex from VB binding 0 and indexes GpuChunkInstance
via gl_InstanceIndex. The compute path needs meshlet_draw.vert to read from SSBOs instead.

The compute+indirect path flow:
1. meshlet_cull.comp -> visible_meshlet_buffer (compact list of visible meshlet IDs)
2. meshlet_emit (integrated into cull or separate) -> meshlet_indirect_buffer (one DrawIndexedIndirectCommand per visible meshlet)
3. vkCmdDrawIndexedIndirectCount using meshlet_indirect_buffer + meshlet_count_buffer

<locked_decisions>
- D-01: Use VB/IB binding approach (Research Approach A) for compute path. Keep vertex/index buffer binding. Each visible meshlet gets its own indirect draw cmd with appropriate offsets into the meshlet vertex/triangle buffers.
- D-02: meshlet_draw.vert uses gl_DrawID (VK_KHR_shader_draw_parameters, core in Vulkan 1.1) to index into visible_meshlet_buffer -> get meshlet_id -> get GpuMeshlet from binding 10 -> get chunk_slot -> get GpuChunkInstance from binding 0. This replaces gl_InstanceIndex indexing.
- D-03: Indirect draw command generation: either integrated into meshlet_cull.comp or a separate meshlet_emit.comp. Decision: integrate into meshlet_cull.comp alongside compaction — each visible meshlet writes both its index to visible_meshlet_buffer AND an indirect draw command to meshlet_indirect_buffer. This saves a separate dispatch.
- D-04: VkDrawIndexedIndirectCommand per meshlet:
  - indexCount = meshlet.triangle_count * 3
  - instanceCount = 1
  - firstIndex = meshlet.triangle_offset (into global triangle index buffer bound as IB)
  - vertexOffset = meshlet.vertex_offset (into global vertex buffer bound as VB)
  - firstInstance = 0 (unused; gl_DrawID is auto-provided via VK_KHR_shader_draw_parameters, core in Vulkan 1.1)
- D-05: meshlet_draw.frag is essentially identical to chunk_mesh.frag (face coloring, texture array sampling). May be a copy or shared source.
- D-06: MeshletPipeline trait:
  ```rust
  pub trait MeshletPipeline {
      fn record_draw(&self, cmd: vk::CommandBuffer, bindless_set: vk::DescriptorSet, camera: &CameraUniforms, meshlet_count_buffer: vk::Buffer, meshlet_indirect_buffer: vk::Buffer, max_draw_count: u32);
  }
  ```
- D-07: ComputeIndirectPath implements MeshletPipeline:
  - Creates graphics pipeline with meshlet_draw.vert + meshlet_draw.frag
  - VB binding: meshlet_vertex_buffer (PackedVertex, stride 8)
  - IB binding: meshlet_tri_buffer (u32 indices, INDEX_TYPE_UINT32 — widened from u8 during upload in Plan 01)
- D-08: Triangle index handling: meshoptimizer outputs u8 local indices. For VB/IB path, convert u8 indices to u32 during upload (MeshletPool::record_upload pads u8 -> u32). This avoids requiring VK_EXT_index_type_uint8. NOTE: This is consistent with Plan 01 D-05 which stores meshlet_tri_buffer as u32[].
- D-09: The old ChunkMeshPipeline and per-chunk draw path are retained but feature-gated. Default path switches to meshlet pipeline.
</locked_decisions>
</context>
