    In `src/runtime/scheduler.rs`:
    - After draining `MeshingState.completed_meshes`, convert each result into
      `RenderDelta::Upsert { key, mesh }`.
    - When a chunk transitions to `Inactive` or `Unloading`, enqueue
      `RenderDelta::Remove { key }`.
    - If `renderer_state()` is `Some`, lock it inside `MeshSync` and call

    - Keep `RenderSubmit` focused on frame submission only; delta generation stays

    - Add `pending_chunk_deltas: VecDeque<RenderDelta>` to `Renderer`.

      `fn record_chunk_delta_uploads(&mut self, cmd: vk::CommandBuffer) -> Result<()>`
    - `record_chunk_delta_uploads` must:
      1. drain the pending queue,
      2. call `ChunkPool::prepare_upload` / `prepare_remove`,
      3. copy only the changed vertex/index ranges into the shared buffers,
      4. update exactly one metadata record and one indirect command template per changed slot.
    - Use a staging buffer or a per-frame upload buffer for those copies.
      Do not call `submit_one_shot_commands` for each dirty chunk, because it
      ends in `queue_wait_idle`.

      `vertex_slot_stride = MAX_QUADS_PER_CHUNK * 4 * size_of::<PackedVertex>()`
      `index_slot_stride = MAX_QUADS_PER_CHUNK * 6 * size_of::<u32>()`
    - On `prepare_remove`, zero the shadow metadata and indirect command and
      return the freed slot id so the caller can write zeros to the GPU buffers.
    - On slot reuse, overwrite stale shadow data before exposing the slot.

    In `tests/phase3_meshing.rs`:
    - Add pure tests against the slot shadows to prove only one slot changes when

    - Assert that removing a chunk clears `index_count`, `instance_count`, and
