<objective>
Close the remaining Phase 3 visual gap: pack_quad() currently encodes all 4
vertices with the same position (quad.origin), producing degenerate zero-area
triangles that generate no fragments. The vertex shader never expands corners
using UV offsets or face index.

Three coordinated fixes are required:
1. pack_quad() must compute actual corner positions per vertex by offsetting
   origin along the quad's u/v plane axes. This requires widening the coordinate
   encoding from 6 bits to 7 bits (max corner value = 64).
2. The vertex shader must decode the new 7-bit layout and add a +1 face-normal
   offset for positive faces.
3. The pipeline front face must change from COUNTER_CLOCKWISE to CLOCKWISE to
   compensate for the Y-flip in debug_project (which reverses winding in window
   space, causing all faces to be back-culled otherwise).

Output: Non-degenerate quads render as visible chunk surfaces in the Revoxelation
window.
</objective>

- D-02: Fix pack_quad corner expansion (Rust), vertex shader decode + face offset (GLSL), and pipeline front-face winding (Rust) in the same plan. All three are necessary: fixing positions alone still produces culled faces due to the Y-flip winding issue.
- D-03: Widen the packed vertex coordinate encoding from 6 bits to 7 bits per axis. After the fix, corner positions range from 0 to 64 (origin 0 + full-chunk size 64). The value 64 requires 7 bits. New word0 layout: x(7 bits, 0-6) | y(7, 7-13) | z(7, 14-20) | face(3, 21-23) | skirt(1, 24).

- D-05: Change pipeline front_face from COUNTER_CLOCKWISE to CLOCKWISE. The debug_project shader negates clip.y, reversing triangle winding in window space. CLOCKWISE compensates for this Y-flip so outward-facing triangles are identified as front faces. This is also the standard Vulkan practice when the projection flips Y.

face_index mapping for reference:
```
(axis=0, positive=true)  => 0  (+X)
(axis=0, positive=false) => 1  (-X)
(axis=1, positive=true)  => 2  (+Y)
(axis=1, positive=false) => 3  (-Y)
(axis=2, positive=true)  => 4  (+Z)
(axis=2, positive=false) => 5  (-Z)
```

Positive faces have even indices, negative faces have odd indices.
face_axis = face_index / 2, is_positive = (face_index % 2 == 0).
