  <action>
    Finish the CPU meshing path up to `PackedMesh`, but stop before GPU upload.

    In `src/meshing/greedy.rs`:
    - Implement a 3-axis greedy face-mask sweep over the 64^3 interior.
    - For each axis and slice:
      1. build a 2D face mask by comparing each solid voxel against the
         neighbor voxel on the positive and negative side,
      2. classify a face as visible only when the current voxel is non-zero and
         the compared voxel is zero,
      3. merge rectangles only when the merge key matches
         `(block_id, axis, positive_face, is_skirt)`.
    - When a coarse chunk is marked by `Lod0NeighborActivated`, emit skirt quads
      only on the faces that border a now-active finer chunk. Encode the skirt
      flag into `PackedVertex.word0` bit 24.

    In `src/meshing/packing.rs`:
    - Add `pub fn pack_quad(quad: &GreedyQuad, vertices: &mut Vec<PackedVertex>, indices: &mut Vec<u32>)`.
    - Emit exactly 4 vertices and 6 indices per quad in a fixed winding order.
    - Fill `PackedMesh.aabb_min` / `aabb_max` from the emitted vertex extents so
      the renderer can build chunk AABBs without re-scanning voxel data.

    In `src/runtime/scheduler.rs`:
    - During `Stage::MeshSync`, after draining streaming job results, call
      `MeshingState.take_dirty_batch(PER_FRAME_CAP)`.
    - For each key in that batch, gather the center payload plus six same-LOD
      neighbors from `MeshingState.payloads`, call `build_greedy_mesh`, and push
      `MeshingJobResult { key, mesh, source_revision }` into
      `MeshingState.completed_meshes`.
    - Keep meshing bounded to `PER_FRAME_CAP`; do not reintroduce full-world
      work in one frame.
